# sebmake-keynote-likeapple-pls

This skill has moved to **[sebmake/LikeApplePLS](https://github.com/sebmake/LikeApplePLS)**, with the three other LikeApplePLS skills. It is now in English, and you can install only the skills you want:

```bash
npx skills@latest add sebmake/LikeApplePLS --skill sebmake-keynote-likeapple-pls
```

Or as a Claude Code plugin:

```bash
claude plugin marketplace add sebmake/LikeApplePLS
claude plugin install sebmake-keynote-likeapple-pls@likeapplepls
```

This repo is archived. Its old releases stay available.
